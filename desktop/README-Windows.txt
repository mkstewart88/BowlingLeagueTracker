Bowling League Helper — Windows Desktop Installer & User Guide
================================================================

1. INSTALLING THE PROGRAM
   - Double-click "installer.exe" inside this folder.
   - It installs all program files directly into C:\BowlingLeagueHelper\
     and places a "Bowling League Helper" bowling ball & pins icon on your Desktop.

2. BACKUP & ONEDRIVE SAVES
   - Click "Save Dated Backup..." in the app to save a file named with today's
     date (e.g. BowlingLeagueHelper_Backup_2026-11-14.json) anywhere you want,
     such as your OneDrive folder.
   - Clearing browser history or cache will NOT delete this program or your saves.

3. AUTOMATIC SAVE ON CLOSING
   - When you close Bowling League Helper, it automatically saves everything
     into your last used save file.
   - If that file cannot be found (deleted, moved, or not set yet), the program
     stays open and asks you to pick a new save location or click "Don't Save".

4. AUTOMATIC UPDATES
   - Click "Update and Restart" inside the top version button whenever a new
     release is available. It updates the files inside C:\BowlingLeagueHelper\
     directly and restarts automatically.
